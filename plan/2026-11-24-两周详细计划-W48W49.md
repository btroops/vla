### D2 · 11/25（周三）· 2 h · 坐标系、位姿、三种表示（上）

### D4 · 11/27（周五）· 2 h · SE(3)、逆变换、左乘右乘

**读**：`docs/01-机器人学数学基础.md` 第 60–82 行（§1.4）。

三处重点：

1. **$T^{-1}$ 有闭式解**：$\begin{bmatrix}R^\top&-R^\top p\\0&1\end{bmatrix}$。这是高频考点也是高频 bug，常见错法是写成 $-p$ 或 $-Rp$。
2. **左乘 vs 右乘**："在位姿后面**右乘** = 在自身动坐标系里做动作；前面**左乘** = 在固定（世界）坐标系里做动作"。口诀"先动的在右边"。
3. 书上第 70 行那个验证（$T^{-1}T$ 右上角为 $R^\top(Rp-p)=0$）自己推一遍。

**做**（70 min）：
- 写 `T_from_Rt(R, t)` 和 `T_inv(T)`
- **故意写错一次**：把 `T_inv` 写成 $-p$，跑 `T_inv(T) @ T`，看它怎么炸。亲手炸一次，比读十遍常见误区记得牢
- 用 `T_inv(T) @ T ≈ I`（atol 1e-9）自查

**验收**：
- [ ] 合上文档默写 $T^{-1}$，并把那个故意写错的版本错在哪讲清楚

### D7 · 11/30（周一）· 2 h · `quat_from_R`（两周里最难的一天）

**为什么单独给它一天**：从旋转矩阵反解四元数有一个数值陷阱——$\mathrm{tr}(R)$ 公式在 $\theta\approx\pi$ 时会除以接近 0 的数，结果直接飘。新手 80% 的"往返误差超大"都出在这里。

**做**（90 min）：
1. 先写朴素版：$w=\frac{\sqrt{1+\mathrm{tr}R}}{2}$，再用 $R(q)$ 公式反推 $x,y,z$
2. 造一个 $\theta\approx\pi$ 的旋转（比如 $q=(0,1,0,0)$，即绕 $x$ 转 180°）喂给它，**亲眼看它飘**
3. 补分支：看 $R$ 的最大对角元决定先求 $x$、$y$ 还是 $z$ 中的哪一个，再由它推其余三个

**验收**：
- [ ] 随机 20 组 $R$ 往返误差 < 1e-6
- [ ] 180° 旋转（$q=(0,1,0,0)$）也稳，误差 < 1e-6
- [ ] 能讲清朴素版在 $\theta\to\pi$ 时为什么失效

### 现成的验收脚本

D9 直接复制到 `projects/M01-se3-rotation/tests/test_rotations.py`。用 `pytest` 跑；没装 pytest 就把 `test_` 开头的函数在 `__main__` 里挨个调一遍，`assert` 一样会报错。

```python
"""旋转表示互转的验收测试。被测实现见 ../src/rotations.py。"""
import sys
import pathlib

import numpy as np

sys.path.insert(0, str(pathlib.Path(__file__).resolve().parents[1] / "src"))
from rotations import (  # noqa: E402
    R_x, R_y, R_z, euler_to_R, R_to_euler,
    T_from_Rt, T_inv,
    quat_from_R, R_from_quat, quat_mul, quat_conj, slerp,
)

rng = np.random.default_rng(0)


def rand_quat(n=1):
    """随机单位四元数，(w,x,y,z) 顺序。"""
    q = rng.normal(size=(n, 4))
    q /= np.linalg.norm(q, axis=1, keepdims=True)
    return q if n > 1 else q[0]


def quat_close(a, b, atol=1e-6):
    """q 与 -q 是同一个旋转，比较时取两者较小的差。"""
    return min(np.abs(a - b).max(), np.abs(a + b).max()) < atol


def test_basic_rotations_orthonormal():
    for R in (R_x(0.3), R_y(-1.1), R_z(2.0)):
        assert np.allclose(R.T @ R, np.eye(3), atol=1e-12)
        assert np.isclose(np.linalg.det(R), 1.0, atol=1e-12)


def test_roundtrip_100():
    """核心验收：双向往返，100 组，误差 < 1e-6。"""
    err_R, err_q = [], []
    for q in rand_quat(100):
        R = R_from_quat(q)
        err_R.append(np.abs(R_from_quat(quat_from_R(R)) - R).max())
        q2 = quat_from_R(R)
        err_q.append(min(np.abs(q2 - q).max(), np.abs(q2 + q).max()))
    print(f"R 往返 max={max(err_R):.2e}  q 往返 max={max(err_q):.2e}")
    assert max(err_R) < 1e-6
    assert max(err_q) < 1e-6


def test_180deg_rotation():
    """theta≈pi 是 quat_from_R 的数值陷阱，必须单独测。"""
    q = np.array([0.0, 1.0, 0.0, 0.0])          # 绕 x 转 180°
    assert quat_close(quat_from_R(R_from_quat(q)), q)


def test_se3_inverse():
    R, t = R_from_quat(rand_quat()), rng.normal(size=3)
    T = T_from_Rt(R, t)
    assert np.allclose(T_inv(T) @ T, np.eye(4), atol=1e-9)


def test_euler_roundtrip():
    for _ in range(50):
        rpy = rng.uniform(-1.3, 1.3, 3)          # |theta| < 75°，避开万向锁
        assert np.allclose(R_to_euler(euler_to_R(rpy)), rpy, atol=1e-9)


def test_gimbal_lock_only_theta_recoverable():
    rpy = R_to_euler(euler_to_R([0.4, np.pi / 2, 0.7]))
    assert abs(abs(rpy[1]) - np.pi / 2) < 1e-6    # theta 可恢复，phi/psi 不可独立确定


def test_quat_mul_matches_matrix_mul():
    for _ in range(20):
        a, b = rand_quat(), rand_quat()
        assert np.allclose(R_from_quat(quat_mul(a, b)),
                           R_from_quat(a) @ R_from_quat(b), atol=1e-9)


def test_slerp():
    q0, q1 = rand_quat(), rand_quat()
    if np.dot(q0, q1) < 0:
        q1 = -q1
    assert quat_close(slerp(q0, q1, 0.0), q0, atol=1e-12)
    assert quat_close(slerp(q0, q1, 1.0), q1, atol=1e-12)

    def angle(q):
        return 2 * np.arccos(min(1.0, abs(q[0])))

    half = angle(quat_mul(quat_conj(q0), slerp(q0, q1, 0.5)))
    assert abs(half - angle(quat_mul(quat_conj(q0), q1)) / 2) < 1e-6


def test_nonunit_quat_is_normalized():
    assert np.allclose(R_from_quat(np.array([2.0, 0, 0, 0])), np.eye(3), atol=1e-12)


if __name__ == "__main__":
    for name, fn in sorted(globals().items()):
        if name.startswith("test_"):
            fn()
            print(f"PASS {name}")
```

## 5. 提示区（先自己想 20 分钟再看）

**提示 1 · `quat_from_R` 的数值稳定性**

$\mathrm{tr}(R)=4w^2-1$，所以 $|w|=\frac12\sqrt{1+\mathrm{tr}R}$。问题在这：$\theta\to\pi$ 时 $w\to0$，$\sqrt{1+\mathrm{tr}R}\to0$，任何一点舍入误差都被放大，于是 $x,y,z$ 全飘。

修法：**先看对角元谁最大**。$R_{00}=1-2(y^2+z^2)$、$R_{11}=1-2(x^2+z^2)$、$R_{22}=1-2(x^2+y^2)$——对角元最大的那个，对应的分量绝对值也最大，先把它开方求出来，再由它推其余三个（都在分母上有它，不会除以 0）。一共四个分支：`trace > 0` 走 $w$ 分支，否则按最大对角元走 $x$ / $y$ / $z$ 分支。

**提示 2 · `R_to_euler`**

$R=R_z(\psi)R_y(\theta)R_x(\phi)$ 展开后，**看这三个元素**：$R_{20}$、$R_{21}/R_{22}$、$R_{10}/R_{00}$。分别是 $-\sin\theta$、$\tan\phi$、$\tan\psi$ 的位置。$\theta=\pm90^\circ$ 时 $R_{21},R_{22}$ 同时趋于 0，$R_{22}$ 一除就炸——那时只能约定 $\phi=0$，把 $\psi$ 全部吸进去。

**提示 3 · SLERP 的判号**

$q_0\cdot q_1<0$ 时取 $q_1\leftarrow-q_1$。这两者在 SO(3) 上是同一个旋转，但四元数空间里是两个反方向的点，不判号就会沿大圆走 360°，看起来姿态"绕了一大圈才到位"。
